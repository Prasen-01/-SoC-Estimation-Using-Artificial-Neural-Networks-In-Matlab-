# -SoC-Estimation-Using-Artificial-Neural-Networks-In-Matlab-
State of Charge (SoC) of lithium-ion batteries can’t be measured directly , it must be estimated.  Traditional methods (Coulomb Counting, Kalman Filters) degrade under real-world conditions (aging, dynamic loads).  This project attempts to solve that using Artificial Neural Networks (ANN) using Matlab . 
It Implements a basic feedforward ANN in MATLAB to estimate SoC using input features: voltage, current, and temperature.Uses simulated or publicly available data — no real-time or live dataset from EV systems.Trains and validates the network using standard supervised learning (no online learning).Evaluates performance via common metrics: RMSE, MSE, correlation (R values close to 0.995).Compares results qualitatively (not deeply quantitatively) with conventional techniques.
